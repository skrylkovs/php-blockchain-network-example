# PHP Blockchain Network Example

Этот проект представляет собой простую блокчейн-сеть, написанную на PHP. Ниже приведено описание основных файлов:

## Файлы и их функциональность

1. **`MerkleTree.php`**  
   - Реализует построение дерева Меркла для транзакций.
   - Хеширует каждую транзакцию и объединяет пары хешей до получения одного корневого хеша.

2. **`Blockchain.php`**  
   - Основной класс блокчейна.
   - Управляет цепочкой блоков (`$chain`) и пулом транзакций (`TransactionPool`).
   - Позволяет добавлять новые блоки (`addBlock()`) и проверять целостность цепи (`isChainValid()`).
   - Создаёт генезис-блок при инициализации.

3. **`UTXO.php`**  
   - Управляет системой UTXO (непотраченные выходы транзакций).
   - Позволяет добавлять (`addUTXO()`), тратить (`spendUTXO()`) и получать баланс (`getBalance()`).

4. **`Block.php`**  
   - Определяет структуру блока в блокчейне.
   - Включает индекс, временную метку, список транзакций, хеши, nonce и сложность майнинга.
   - Реализует вычисление хеша (`calculateHash()`) и процесс майнинга (`mineBlock()`).

5. **`TransactionPool.php`**  
   - Управляет пулом неподтверждённых транзакций.
   - Позволяет добавлять транзакции (`addTransaction()`), получать их (`getTransactions()`) и очищать пул (`clear()`).

6. **`Transaction.php`**  
   - Описывает структуру транзакции (отправитель, получатель, сумма, время).
   - Поддерживает преобразование транзакции в JSON (`toJson()`).

7. **`Node.php`**  
   - Реализует узел сети блокчейна.
   - Управляет локальным экземпляром блокчейна.
   - Позволяет добавлять транзакции (`addTransaction()`), майнить (`minePendingTransactions()`) и отображать блокчейн (`showBlockchain()`).

8. **`Wallet.php`**  
   - Реализует криптовалютный кошелёк.
   - Генерирует приватный и публичный ключи.
   - Позволяет подписывать транзакции (`signTransaction()`).

9. **`Miner.php`**  
   - Реализует майнинг блоков.
   - Добавляет награду за майнинг (`REWARD`).
   - Вызывает `addBlock()` для включения транзакций в цепочку.

10. **`P2PNetwork.php`**  
   - Реализует одноранговую сеть блокчейна.
   - Позволяет добавлять узлы (`addNode()`).
   - Распространяет транзакции (`broadcastTransaction()`) и блоки (`broadcastBlock()`) между узлами.

Эти файлы вместе создают полноценную блокчейн-сеть с узлами, транзакциями, майнингом и одноранговым взаимодействием.
